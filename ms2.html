Introduction

Introduction

Congratulations on your purchase of MoonSound Music Studio, the program that makes it possible to use your MoonSound cartridge to its full potential.

MoonSound Music Studio will be referred to as MS² for the rest of this manual.

Getting Started

Requirements

MS² requires the following minimum configuration:

  • MSX2 or higher computer with 128kB VRAM
  • 256kB memory mapper*
  • MoonSound
  • MSX-DOS2

* Note that on a Panasonic FS-A1ST memory is quite tight, so MS² will deallocate the R800 DRAM mode segments. After exiting the program, the MSX will remain in ROM mode and DRAM mode cannot be re-enabled without the MSX crashing.

The following additional hardware is supported:

  • 512kB to 4MB memory mapper, for increased song size.*
  • MoonSound with 4MB Sample RAM, such as Dal-So-Ri R2.

* Only the primary Memory Mapper is used, so on MSXturboR this will likely be the internal one.

Faster CPUs such as Z80 5.37MHz, Z80 7.16MHz or R800 can be used with this program.

Starting the program

MS² can run straight from diskette, or be installed to other media supported by MSX-DOS2. Installing is done by simply copying the MS² program files (MS2.*) to the desired location and optionally adding it to your PATH.

You can start MS² by executing MS2.COM and it will automatically look for the data files at the MS2.COM location.

After loading you will enter the Music Editor.

General operation

Move around with the CURSOR keys.

ESC exits menus, screens, and input fields. In places where confirmation with [RETURN] is expected, it discards.

RETURN confirms input, and enters deeper levels or edit functions.

SPACE opens lists and selects choices.

In every menu where settings can be done, you can modify a setting with CTRL+CURSOR or + or -. Generally, UP increments, DOWN decrements, LEFT decrements in coarse steps, and RIGHT increments in coarse steps.

Initial setup for 4MB Sample RAM support

To prepare your Instrument Libraries for use in Dal-So-Ri R2's 4MB RAM mode, make sure you have more than 2MB free diskspace and perform the following two steps once:

  • Set your Dal-So-Ri R2 to 2MB RAM mode (ie. ROM enabled) and start MS²
  • Load the Instrument Library file (eg. MBMS.MS2) as a song, and immediately save it again. This will couple all the samples in the Yamaha ROM with the instruments in the Instrument Library.

Now you can set your Dal-So-Ri R2 to 4MB RAM mode and load existing songs, as well as start composing songs for any MoonSound compatible hardware!

Music Editor

Introduction

When MS² has started you will be greeted with an empty song, which you can start editing right away.

A song consists of some information and settings, but most importantly of patterns of music. Analogous to sheet music, a pattern is like a single bar of a score. A pattern is divided into a grid of rows (called steps) and columns (called channels). Every cell in this grid can hold one or more events, which describe effects and notes. An empty cell is shown as " - ", while one with multiple events will have a fat border on the right. All events on the same step will be played together at the same time.

Navigating

The cursor keys are used to move through the pattern grid. If there are more channels available than fit on the screen, the cursor will scroll through all available channels.

Move through the patterns with CTRL+UP/DOWN, move 4 patterns at once with CTRL+LEFT/RIGHT.

As you navigate past the end of the song, new empty patterns will be created automatically.

To return to the start of the song, press HOME.

Playing the song

To start playing the song, press F1. The song play from the currently displayed pattern and keeps playing until the song ends. If an error is found the playing will stop and the cursor will be placed at the exact location of the error.

Playing can be stopped manually with STOP or SPACE. It will stop the music at the current position, to allow you to edit from that point. Alternatively, music can be stopped with ESC, which restores the editing position to where it was before playing.

Turning channels on and off

Each channel can be turned off, so you can remove specific channels from playback. To do this, move the cursor to a channel and press CTRL+O. The header will display "OFF". Repeat the same to turn it back on.

Note that global events are also ignored if they are on a channel that is turned off.

Solo play

When you want hear one specific channel, you can switch a channel to "solo" play. To do this, move the cursor to a channel and press CTRL+S. The header of all other channels will display "OFF". Repeat the same to turn the other channels back on.

You can combine this with the previous function to turn on additional channels, for example to listen to a small number of channels.

Resetting a song

The whole current song can be reset by pressing F10. You will be asked for confirmation.

Events

Introduction

An event is input on a cell by pressing its designated key. ESC cancels the input, With BS you can correct a mistake. To confirm the input, press RETURN. Removing events in a cell is done with DEL.

The last event can be repeated by pressing CTRL+Y on another cell.

Notes

Notes in MS² are specified and presented in scientific pitch notation, meaning an A in octave 3 will be "A 3", a C sharp in octave 5 "C#5", and so on. "C 4" is middle-C and "A 4" is 440Hz in equal temperament. Octaves 1 through 8 are supported.

There are two ways to input notes using the MSX keyboard. You can alternate between them with CAPS. Note that SHIFT has no influence on this.

TYPE (CAPS light off): Notes are input like any other event, using A through G. Then you can add a sharp or flat, respectively with + or # and - or b, or simply toggle by repeating the note key. Finally add the octave using 1 through 8.

1KEY (CAPS light on): The MSX keyboard turns into a two octave piano-like keyboard. The base octave can be set with GRAPH+CURSOR. The following keys are used in this system:

 2 3   5 6 7
Q W E R T Y U	(upper octave)

 S D   G H J
Z X C V B N M	(lower octave)

So Q or Z input a C. For a G# you press 6 or H. Other keyboard keys are unused in this mode, so if you want to enter an event other than a note, switch to TYPE.

If Note Auditioning is turned on, you will hear the note after you input it.

Legato Notes

Using legato you can play another note without rearticulation. The new frequency is played without restarting any envelopes. A legato note is indicated by a lower case letter and can be input by keeping SHIFT pressed while inputting the note letter.

Note Off

To stop playing a note, a Note Off event must be used. The key for this is O and it will show up as "---" in the pattern.

Instrument Change

Changing the instrument during a song requires an instrument change event. This is input with @ followed by the number of the instrument as defined in the Instruments Manager. Note that for FM instruments, because it's inherent in the instrument definition, the volume changes too.

Tuning change

Tunings defined with the Tuning Editor (F8) can be used to modify the frequency of each note slightly, or by a lot. It allows you to create detuned instruments, classic temperaments, exotic music systems, and more. A tuning change is entered with U followed by a number. The tuning change will take effect when a new note is played.

Stereo Panning

With S a stereo panning value from -7 to +7 can be entered. For channels that just allow left/center/right panning, -7 to -3 means left, -2 to +2 means center and +3 to +7 means right.

Volume Change

The volume of a channel can be changed with V. The value ranges from 0 (minimum) to 63 (maximum). On FM this sets the Total Level of FM operator 2.

Pitch Envelope

Pitch envelopes allow you to control the pitch of a channel continuously, based on the music timer. It can be used to implement slides, vibratos, temporary detunes, and more creative possibilities. MS² predefines 18 envelopes for you, which correspond to different levels of up and down slides. These are input with P, then + or -, followed by a number 1 through 9. In addition to these, you can define custom envelopes, which are input with M and then a number.

These envelopes can be edited by pressing CTRL+P. Add envelops by moving to the right. Use INS and DEL to insert or remove steps. To remove the envelope, simply delete the last step, which will ask you to confirm. The loop point can be changed, or disabled.

Each timer period, one step is processed and the frequency changes by 0 to 9 units up or down. One unit is 3 cents for WAV channels and 6 cents for FM channels. This distinction is an unfortunate legacy of MoonBlaster.

Envelope Off

An envelope can be stopped with the "Envelope Off" event, which is input as P + 0 or P - 0. It is displayed as "-e-". The pitch will stay fixed at the last level.

MoonBlaster FM Legacy Events

These events apply only to FM instruments.

Brightness Change

The Brightness Change event is a relative operation on the Total Level of FM operator 1. Input it by X, then + or - and a number 1 up to 6.

MoonBlaster Wave Legacy Events

These events apply only to Wave instruments.

LFO Settings

The LFO settings entered by W and a number from 1 to 9. With this option you can alter the LFO speed, Vibrato depth and Tremolo depth of a wave currently playing on a channel. Note that this overrides the LFO settings of the instrument. The values of these LFO settings can be set as you like by using the LFO Editor CTRL+W.

LFO Toggle

The LFO from any wave can be toggled on and off with the LFO event. You enter this by pressing Y.

Reverb on

The OPL4 has a built-in pseudo-reverb and this can be enabled with R. The pseudo-reverb will be applied starting from the next note. What this means is that after the Attack phase, when the ADSR envelope reaches -18dB, the OPL4 will stop processing the ADSR envelope and apply Decay/Release rate 5.

Reverb off

The pseudo-reverb can be set off by entering Q.

Global Events

Tempo change

With T the tempo of the song can be changed. The song tempo display is used to enter this event. A tempo change is displayed as "TMP". You can check the value of a tempo change event by editing the cell and checking the song tempo display.

End of Pattern

This option can end a pattern before the 16th step. It is entered with N and displayed as an "END". Usually a pattern has 16 steps, but with an END on step 7 the pattern will end after playing step 7. This function is useful to create for example a 3/4 time.

Transposition

You can transpose the entire song by up to 24 semitones up or down. Each note will be shifted by a the same number of semitones (chromatic transposition) This event is entered with L. Next, enter a value from -24 (2 octaves down) till +24 (two octaves up). Note that the transposition is not relative to any previous transposition. A transpose event is displayed for example "+12" or "- 6". Transposition occurs from the next step onwards. Wave instruments that have the Transpose Inhibit flag set, will not transpose. This is useful for percussion instruments for example.

Advanced Editing

Inserting and deleting patterns

Insert and delete patterns with CTRL+INS and CTRL+DEL respectively. Adding patterns at the end of the song happens automatically when you navigate to them.

Block Selection

You can select part of the song as a block and perform edit functions on contents of the block.

Set the start and end points of the block with CTRL+B. The block selection will be displayed in the highlight colors and can span multiple steps, channels and patterns. You can toggle a block selection on and off with CTRL+D. When a block is toggled off, a new block can be started with CTRL+B.

Copying a Block

With CTRL+C the selected block will be copied with to current cursor position.

Clearing Cells, Channels or Patterns

To clear the cell that the cursor is on, press DEL. If the cursor is in a block selection, the whole block can be cleared. SHIFT+DEL will clear the channel (in the current pattern). The whole pattern can be cleared with SHIFT+HOME.

You will be asked for confirmation when clearing a block or a pattern.

Cell Editing

You can edit a cell by pressing RETURN. This allows you to add and remove multiple events on the cell. The functions mentioned below can also be used while in the cell editor, applying only to the cell.

Transposing channels

Channels can be transposed by semitone or by octave. To transpose up by a semitone use . and to transpose down a semitone use ,. To transpose by octave you can use > for up and < for down. The channel with the cursor on it will be transposed. If the cursor is in a block selection, the whole block will be transposed.

If this operation fails due to a limit being reached, the cursor will move to the first point of failure.

Volume Modification

It is also possible to change all the volumes up or down in a channel by use of [ for up and ] for down. If the cursor is in a block selection, the whole block will be modified.

If this operation fails due to a limit being reached, the cursor will move to the first point of failure.

Toggling Legato on Notes

It is also possible to toggle legato on all the notes in a channel by way of /. If the cursor is in a block selection, the whole block will be modified.

Instruments

Introduction

MS² supports 3 types of instruments, 2-operator FM, 4-operator FM and Wave instruments. Instruments can be managed via the Instruments menu, which is opened with F3.

The music keyboard is active in the instruments menus, so currently selected instruments can be tried out.

Settings such as volume and, in case of Wave instruments, Level Direct and Transpose Inhibit, can be changed by using the cursor keys and potentially combined with CTRL.

Managing instruments

Adding instruments

Instruments can be added using INS. The maximum amount of instruments you can use is 255.

Deleting instruments

Instruments can be deleted using DEL. References to subsequent instruments in the song will be modified to reflect the deletion. If an instrument is in use, you will be asked for confirmation first.

Selecting instruments

Instruments can be selected from the current Instrument Library with SPACE. A list of instruments will pop up, and you can use the cursor keys to walk (and scroll) through the columns.

Naming instruments

Instruments can be (re)named using F6.

Editing instruments

Every instrument can be edited with RETURN. See the chapter Editing Instruments.

Editing Instruments

Envelope

Envelopes used by MS² have 4 phases: Attack, Decay, Sustain and Release. This is also known as an ADSR envelope. Each phase has a speed rate; at rate 0 the level doesn't change and at rate 15 the change is immediate. Additionally, there is the Decay Level that controls the transition between Decay and Sustain phases, and a Rate Scale that can scale the speed rates.

Attack

The speed at which a sound swells up. When the maximum volume is reached, it automatically transitions into the Decay phase.

Decay

The speed at which a sound fades away until the Decay Level is reached.

Decay Level

The volume Level at which the Decay phase ends. Note that at -0dB it happens immediately (Decay phase is ignored), and at -93dB it doesn't happen (Sustain phase is ignored).

Sustain

The speed at which a sound fades away below the Decay Level. Note that for FM instruments, this value is either 0 or a copy of the Release rate.

Release

The speed at which a sound fades away after the key is released (OFF event).

Rate Scale

The strength of the increase of Attack, Decay, Sustain and Release speeds at higher frequencies. Note that for Wave instruments this effect can be turned off completely.

LFO (Low Frequency Oscillator)

The LFO allows you to modulate the frequency or volume of a sound.

Frequency

Sets speed of the oscillation.

Vibrato

Modulates the frequency of the sound.

Tremolo

Modulates the volume of the sound.

Wave Instruments

The MoonSound does sample-based synthesis (often incorrectly referred to as wavetable synthesis), which means sound is generated with pieces of digitized sound. Such a piece is called a sample or a waveform. The MoonSound combines each sample with extra information, such as ADSR and LFO envelopes, which is referred to in MS² as a wave.

Because samples degrade in quality when played at frequencies that lie far from its inherent sampling frequency, Wave instruments in MS² can make use of multiple waves. The definition of which wave is played over which range of notes and at what pitch, is called a split.

Splits are inserted with INS and deleted with DEL. Changing the Note and Cents columns is done with CTRL+UP/DOWN for small steps and CTRL+LEFT/RIGHT for big steps. Press SPACE on the sample columnn to select from currently available samples in OPL4 memory.

The pitch of a wave is defined as the frequency difference from 44.1kHz expressed in musical cents. A note is 100 cents and an octave is 1200 cents.

The following formula will allow you to use arbitrary sampling frequencies:

cents = 1200 * log2( f / 44100 )

(f is the sampling frequency of your sample in hertz)

Samples

MS² supports samples in 8, 12 or 16 bit PCM, sampled at any frequency. Because MS² supports arbitrary frequencies, it's possible to use samples that optimally balance quality and size.

Length: The amount of samples of the sample, at the of the length the sample will continue playing at the loop address. Note that when playing the sample at high frequencies, the OPL4 hardware may overshoot the end address and garbage will be played.

Loop address: The offset in samples from the where sample will loop.

The end and loop address can be changed by 100 with CTRL+UP/DOWN. You can set the loop address to the end address and the end address to the start and sample end with SELECT. The sample name can be changed with F6.

Tunings

Tunings can be used to modify the frequency of each note slightly, or by a lot. It allows you to create detuned instruments, classical temperaments, non-western tone systems, microtonal music, and more.

Enter the Tuning Editor by pressing F8. The expected keys work here as well. You can change entire octaves or a note on all octaves by moving the cursor to the column header or row header respectively.

Instrument Libraries

An Instrument Library is a set of instruments (and tunings) that can be selected for use in your songs. The supplied library "MBMS.MS2" is the complete set of instruments from MoonBlaster for MoonSound FM and WAVE.

The Instrument Library can be (temporarily) swapped with the current Song. This allows you to easily edit it, save your changes, or load a different one. When you're done you can continue working on your song by swapping again. Using this feature you can also pick instruments from other songs, and build your own library!

Note that modifying the "MBMS.MS2" library affects the import of MoonBlaster songs. You are free to edit it to change the results of the MoonBlaster import function though. For example you might want to adjust the Tunings to avoid the emulation of the faulty detune algorithm in MoonBlaster. You could also reorder or replace some instruments. However, be careful not to change the amount of items in the library, because doing so might result in undefined behavior and crashes when importing MoonBlaster songs.

Song Settings

General Settings

Description

A description for the song, such as its name and author, can be modified with CTRL+N. The cursor will appear in the top screen and the description can be entered. With RETURN the new name will be used, with ESC the operation will be cancelled and the old name is still used.

Tempo

With CTRL+T the start tempo can be modified. The tempo is indicated in quarter notes (or beats) per minute and it's assumed that you use a pattern per bar, so four steps is a quarter note. Changing the tempo is done with the cursor keys. Left/right for coarse changes and up/down for fine changes. The tempo is a mathematically based on the timer frequency, so if you change that it will also affect the tempo.

A delta indicator shows the amount of swing between each step for the given timer frequency. On tempos that approach the timer frequency, the amount of swing can be audible by people who are sensitive to this. The higher the ratio between the tempo and the timer frequency, the smaller the contribution of a high delta becomes in the feel of the tempo.

Timer

Use CTRL+F to switch between VDP, 50H and OPL timer. The VDP timer frequency depends on whether a 50Hz or 60Hz display frequency is used. The display frequency can be set in the MS² Configuration. However, 50H timer can be chosen to make sure that the tempo will be nearly identical on 50Hz and 60Hz displays. This timer does add a little bit of extra swing to the tempo. In order to have the most stable tempo, the OPL timer can be used instead of the VDP.

The OPL timer has a resolution of 80.8 microseconds and is selectable from 1 to 133 times that period, which is respectively 48.5Hz to 100.6Hz.

Modulation Depth

Loop Pattern

A song can play indefinitely when you set a loop pattern. This is the pattern where the song will loop after it has played the last pattern. A loop pattern can be set with CTRL+L. After that the pattern can be altered with the cursor keys. Pressing RETURN will confirm the modification and ESC will cancel it. The music will end after the last pattern when 'OFF' is set as the loop pattern.

Song Settings Menu

The Song Settings Menu is accessed with F4 and is where you control everything to do with channels. Channels can be inserted with INS and deleted with DEL. Channels that contain notes will require confirmation before they are deleted. The type of each channel, the default instrument, the volume (in case of WAV channels), and the stereo panning can also be set.

File Management

File menu

The file menu is opened with F5. Depending on the current context, you will get different options. For example, in the music editor you will have the option to load, save and import music, while in an instruments manager, you can import instruments and/or samples.

The file selector allows you to change drives (indicated by parenthesis), subdirectories (indicated by square brackets) and select files. Use the cursor keys to select something and press SPACE or RETURN to confirm.

Instead of selecting a file, you can also start typing a filename you want to use. Press RETURN to confirm, or ESC to cancel.

The file selector allows you to delete files with DEL.

Load

Open the file selector to load a MS² file.

Save

Open the file selector to save a MS² file.

Import

Import a file by file type. Depending on the context you might get additional choices.

Browse

Browse files of all types.

Supported file formats

MoonSound Music Studio

The native MS² format contains all data pertaining your song and can be loaded and saved.

MBFM and MBWAVE Song

MS² takes special care to import MoonBlaster for MoonSound music (MFM and MWM files) as faithfully as possible.

For songs that require a wavekit (MWK) please note that, contrary to MoonBlaster itself, MS² requires the wavekit filename stored in the MoonBlaster song to be correct and available in the same directory.

    Bugs in MoonBlaster for MoonSound that are simulated by MS²:
  • Level Direct only works for Start Voices and then remains fixed at that setting.
  • Level Direct bit leaks into the instrument volume.
  • For FM channels, linked notes (legato) do key-on when key was off. At song start, the base note is B4. Out of bounds note links are ignored.
  • MBFM wrongly assumes an OPL3 at 3.58MHz, making songs played in the MBFM editor detuned down slightly, compared to the MBFM replayer that correctly bases its frequencies on 33.8688MHz OPL4. MS² implements this by applying detune to MBFM EDIT songs and not to MBFM USER songs.

Because MS² goes out of its way to accurately simulate MoonBlaster's many bugs, peculiarities and faulty concepts, it can often be the case that songs can be cleaned up considerably. Please take this into account when updating your MoonBlaster music.

MB 1.4 Song

MS² takes special care to import MoonBlaster music (MBM files) as faithfully as possible. There is real support for MSX-MUSIC instruments. MBMs that are set to MSX-MUSIC will therefor import properly and sound the way they're supposed to. Even things like the volume and brightness events are limited appropriately.

Additionally, MB-STEREO songs are converted to 18 channels, with MSX-AUDIO on the right and MSX-MUSIC on the left, according to MB1.4 recommendations, each with its own instruments.

For songs that require a samplekit please note that, contrary to MoonBlaster itself, MS² requires the samplekit filename stored in the MoonBlaster song to be correct and available in the same directory.

    Bugs in MoonBlaster 1.4 that are simulated by MS²:
  • Linked notes (legato) do key-on when key was off. At song start, the base note is C2. Out of bounds note links are ignored.

Because MS² goes out of its way to accurately simulate MoonBlaster's many bugs, peculiarities and faulty concepts, it can often be the case that songs can be cleaned up considerably. Please take this into account when updating your MoonBlaster music.

    Issues with MoonBlaster 1.4 import that cannot be solved:
  • Due to small hardware differences, like clockspeed, MSX-AUDIO and MSX-MUSIC music might theoretically not sound 100% the same on MoonSound. You would probably need a measuring device to notice this though.
  • Modulation Depth (DAM/DVB) also applies to MSX-MUSIC channels in MB-STEREO music, even though MSX-MUSIC did not have this feature.

MoonBlaster Wavekit

MoonBlaster Wavekits (MWK files) can be loaded.

MoonBlaster Wave

MoonBlaster Waves (MWV files) can be loaded.

MoonBlaster Tone

MoonBlaster Tones (MTN files) can be loaded by selecting a split and opening the file menu with F5.

Samples

In the Wave Instruments Manager you can load raw samples. Press F5 while in the split editor. A selection between 8 and 16-bit, signed and unsigned PCM is possible. Yamaha ADPCM raw samples (MBS files) can also be imported and will be converted to 8-bit PCM.

Configuration

Enter the Configuration screen with CTRL+U. Configuration is automatically saved on program exit. The filename is MS2.CFG.

Appendix B: Troubleshooting

I've input some notes but don't hear anything when playing.

Make sure you've defined instruments for your song.

I've loaded a sample but don't hear anything when playing.

Make sure you define appropriate ADSR envelope parameters.

I got a message "Uncaught exception!" and MS² stopped.

This is a serious error which should be reported. Please contact TNI with a description of what happened.

Appendix C: For MoonBlaster users

Although MoonSound Music Studio is originally based on MoonBlaster, it has many differences in usage and concepts. This section is intended to help people migrate from MoonBlaster to MS².

There is no difference between 'own' instruments and 'built-in' instruments. The principle of "Own Voice" and "Own Wave" is gone.

Tempo is specified in quarter notes (or beats) per minute. Both VDP and OPL timer are usable.

Wave volumes are doubled in resolution to 64 steps, so they have the same resolution as FM volumes.

Wave instruments no longer have an inherent volume, so changing a wave instrument leaves the current volume unchanged. This is why wave instrument changes on MFM/MWM imports take up two events now. Start volumes for wave channels can be set in the Song Settings menu.

The "OFF" event is displayed as "---". This allows reading of notes with less distraction and results in a much more structured view.

Stereo events are shared for FM and Wave. For FM channels, -7 to -3 are LEFT, -2 to +2 are CENTER and +3 to +7 are RIGHT.

In the music editor, CTRL+up/down and CTRL+left/right are swapped.

Instead of just 64, the full amount of 128 samples can be used. With 4MB Sample RAM even 512 samples can be used!

Samples larger than 65531 bytes can be loaded and MS² does not add 4 bytes of silence to them, so you can create loops without having to manually modify the sample end points differently for different sample types.

Appendix D: Using MS² music in your own software

The external replayer "MS2PLAY" is a binary library with a flexible interface. It includes the actual player used internally by MS² to ensure music sounds the way the composer intended. You can read its documentation in the MS2PLAY.ASM file, which also includes the source code for a simple stand-alone player program for MSX-DOS2, showing one possible implementation of MS2PLAY. It can be assembled with tniASM.

Event Callback

A callback can be defined for monitoring or modifying the event stream.

Appendix E: The MS2 File Format

The MS2 file format is a chunk based. After the file signature, the file contains only chunks. Chunks are loaded in order of appearance. Multiple chunks of the same type can exist in a file. In the description below, 'word' refers to 16 bits, 'tribyte' to 24 bits, and 'long' to 32 bits. A 'signed binary cent' is a signed offset in units of the width of a semitone interval in 12-tone equal temperament divided by 128. ASCII fields are padded with spaces.

Pattern data

Pattern data is an MML-like array of variable size, consisting of event data and time length codes. The maximum number of events before a time length code is 5. Time length codes have bit 7 set and the value 1 ~ 16 in the lower bits. Time length 1 is considered to be a 16th note, time length 16 is a whole note. For each channel, event data and time length codes alternate until time length 16 is reached.

Pitch Envelope data

Pitch Envelopes are arrays of variable length, containing 8-bit integers with values from -9 to 9. The Pitch Envelope is ended by a 10 and then either a 0 or a positive value. A 0 stops the envelope, but another value indicates a loop. The minimum loop value is 2, which loops to the value before the 10.
