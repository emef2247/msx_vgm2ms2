

https://github.com/emef2247/msx_vgm2ms2　概要

	https://github.com/emef2247/msx_vgm2mml ではvgmから楽譜情報・noteを読みより、アウトプットとしてMGSDRVのMMLで出力することを実装しました。
	次のステップとしてMoonsound MusicStudio(MS2)のファイルフォーマットに出力することを目指します。
	vgm2mml.pyをベースにvgm2ms2.pyを作るのが目的です。

	現在の状況・ MileStone 1
	現状ではOPLLのvgmを読み込んで、ノート情報をMMLとして書き出す部分まで実装ができています。
	一方で音色情報をMMLとして書き出す処理はできていません。
	今回は、まずMS2のファイルフォーマットで書き出すことを目標にしているので、まずはMS2のファイルフォーマットを満たせるように音色情報を扱えるようにしたいと思います。
	https://github.com/emef2247/msx_vgm2ms2/blob/main/ms2.html
	をチェックして、
	Appendix E: The MS2 File Format
	の内容を理解してください。
	これをカバーできるようなフォーマットを持つvgm2mml.pyを考えてください。
	そして、音色情報が変わった場合に、まずはMMLで出せるようにしてみましょう。
	MS2はMSX用プログラムなので、実行に少々手間がかかります。
	pyスクリプトとして音色情報を正しく扱えているかどうかをvgm2mml.pyで確認するのがまず第一段階です。
	これができるようになったら、MS2のファイルフォーマットで出力して、MS2でテストしていきます。

OPLLについて
	また、srcには参考情報として、https://github.com/emef2247/eseopl3patcher のコードを置きました。
	https://github.com/emef2247/eseopl3patcher　はOPLLのVGMを読み込んで、OPL3用のVGMに変換するコンバータです。
	OPL3の情報やOPLLのデータを扱う上で参考になると思います。
	こちらのコードもチェックしてOPLLのデータを扱いかたについて把握しておいてください。


	OPLLから他のFMチップに変換する方法は、以下の方法が一番堅牢です。
	https://github.com/digital-sound-antiques/vgm-conv/blob/main/src/converter/ym2413-to-opl-converter.ts

	また、これをベースにCで実装したのがeseopl3patcherになります。
	https://github.com/emef2247/eseopl3patcher/blob/main/src/main.c
	https://github.com/emef2247/eseopl3patcher/blob/main/src/opll/opll2opl3_conv.c
	https://github.com/emef2247/eseopl3patcher/blob/main/src/opll/ym2413_patch_convert.c
	OPLLのROMSETは以下のコードで網羅しています。
	https://github.com/emef2247/eseopl3patcher/blob/main/src/opll/ym2413_voice_roms.h

## MileStone 1 Phase 1 – OPLL Voice Table (実装済み)

### 概要
OPLL(YM2413)の音色情報を「音色テーブル」として管理し、MML出力で `@<voice_id>` を使用するように変更。

### 追加ファイル・変更点
- `py/vgm_reader.py`:
  - `_OpllState` に `user_patch[8]` 追加。reg 0x00-0x07 の書き込みを追跡。
  - `output_voice_csv()` 追加: `*_trace.opll_voice.csv` を生成。
    - `#type,time,ch,ticks,inst,vol,patch_hex` の7列構成。
    - type='patch': ユーザーパッチレジスタ更新(ch=-1, global)
    - type='instVol': チャンネル音色変更 + 現在のパッチスナップショット
  - `parse_vgm()` の戻り値を7要素に拡張(7番目が `opll_voice_csv` パス)。

- `py/opll_mml.py`:
  - `_Segment` に `voice_id` フィールド追加。
  - `_assign_voice_ids(segments, voice_csv_path)` 追加:
    - inst!=0: voice_key = ('preset', inst)
    - inst==0: voice_key = ('user', patch_bytes) <- voice CSVのpatch_hexから取得
    - voice_id は 0..N-1 の連番
  - `_voice_table_comments(voice_table)` 追加: MMLヘッダに音色定義コメントを出力。
  - MML出力: `@{inst}` -> `@{voice_id}` に置き換え。
  - pass0.csv に `voice_id` 列を追加。
  - `process_opll_csv()` に `voice_csv_path` 引数を追加(省略可、後方互換)。

- `vgm2mml.py`:
  - `parse_vgm()` の7要素を受け取るよう更新。
  - `process_opll_csv()` に `voice_csv_path` を渡す。
  - 非デバッグモードで `opll_voice_csv` もクリーンアップ。
